# MIPS-Average-Score-Calculator
This program is a MIPS assembly script that takes in user input for the number of assignment grades, followed by scores for each assignment.
The program performs a selection sort on the input array, arranging the values in descending order.
It then asks the user how many of the lowest scores to drop.
The program removes the lowest scores, now at the end of the array, then calculates and prints the average of the remaining scores.

This repository also includes a copy of MARS (MIPS Assembler and Runtime Simulator), which is needed to simulate a processor that can run this code.
This Java runtime is included only to provide a way to run the program, and the developer of this repository makes no claims of ownership.
