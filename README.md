# MIPS-Average-Score-Calculator
This program is a MIPS assembly script that takes in user input for the number of assignment grades, followed by scores for each assignment.
The program performs a selection sort on the input array, arranging the values in descending order.
It then asks the user how many of the lowest scores to drop.
The lowest scores, now at the end of the array, are removed, and the program calculates and prints the average of the remaining scores.
